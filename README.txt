MEMORY MARKET
A first-person narrative sci-fi mystery set in Dhaka, 2087.
GameJamPlus Bangladesh 2026/27 entry. About 12-20 minutes.

HOW TO RUN
1. Unzip this folder.
2. Double-click index.html (Chrome, Edge or Firefox; a desktop browser with WebGL).
   No install, no server, no internet needed. Three.js is bundled in lib/.
3. Click "Begin". Headphones recommended.

CONTROLS
  W A S D / arrow keys   Move
  Mouse                  Look (click the game to capture the mouse; Esc releases it)
  Shift                  Sprint
  E                      Interact / advance dialogue
  Tab                    Evidence journal
  Q                      Memory Analyzer (unlocks in Chapter 3)
  1-4                    Pick a dialogue choice
If the mouse cannot be captured, hold the left button and drag to look.

THE ARGUMENT
The final debate is deterministic; there is no live AI. What you collected earlier
decides what you can say to MNEMOS. Look closely at every room, and read everything.
There are four endings, including one secret ending.

OPTIONS
Volume, and MNEMOS voice (browser speech) on/off, are in Options on the title screen.
